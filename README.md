# 郷野の家 — Rural House Walk

ブラウザだけで歩ける、完全オリジナルの3D田園住宅散策アプリです。

- 一人称視点：WASD / 矢印キーで移動、マウスで視点操作
- Shift：ダッシュ
- F：近くの建具を開閉
- Esc：マウスロック解除
- スマートフォン：画面上の仮想スティック＋スワイプ視点操作
- 住宅内部、縁側、庭、畑、物置、小道、樹木、生活家具をコード生成
- 外部の画像・3Dモデル・映画／アニメ作品の図面は使用していません

## 権利面の設計方針

本アプリは、昭和中期の日本の木造住宅・田園生活に見られる一般的な建築要素を題材にした独自設計です。特定の映画、アニメーション、キャラクター、実在展示施設等の名称・間取り・外観・家具配置・意匠を複製していません。
